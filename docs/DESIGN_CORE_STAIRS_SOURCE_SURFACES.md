توجد23 هندسة داخلية فريدة و6 نسخ لقوالب مشتركة. تُنسخ vertices/faces بـdeepcopy ثم يوضع source pose فقط. التنسيق العددي الداخلي12 منزلة يلغي ضوضاء float فقط؛ أقصى فرق يوثّقه الدليل أقل من1e−9 سم. كل اختلاف شكل/عرض أصلي ينشئ قالبًا مستقلًا؛ لا تقريب تشابه إلى0.2 ولا scale/warp.
