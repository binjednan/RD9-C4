## API والتكامل

`apply(M,els=None)` يصحح المضيف والنوع والمادة فقط، مستقل عن DD. حارس الكائن الكامل يقبل القديم المحفوظ أو المصحح، ويسمح للكائن الناتج مباشرة من المولد بغياب q فقط، ويرفض أي حقل مخالف آخر.

`issue_records(M)` يعيد بطاقتي correctedXY وsource_gap بعد حارس المضيف؛ `apply_issues(M)` يستبدلهما منفصلًا. لا يحول الحاجز إلى عنصر إنشائي مقبول.

`post_model.py.proposed`: الاستدعاء بعد إعادة أجزاءD16 عند الموضع815–817، ثم إسناد النوع والمادة بعد تحديث TYPES. هذا الموضع ضروري لوجود الأبواب الأربعة قبل الحراسة. `drawing_deviations.py.proposed`: يحفظ حارس الحالة القديمة، ويستبدل assertion القديم عند ظهور التصحيح بالحارس الجديد وبطاقتي المصدر. لا يشغل شيئًا.

نسخ الوحدة إلى pipeline والبيانات إلى pipeline/data؛ الوحدة تقبل ملف بيانات شقيقًا أو مجلد data وتفحص SHA المجمدة وSHA أصلَيPDF. الجذر يتولى refreshCC واحدًا، مادةunknown فيMR، وإعادة استعمال اعتمادLC حسب المعرف الثابت.
