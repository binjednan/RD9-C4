# إغلاق القسم المعماري (خارجي + داخلي) — قائمة الإغلاق

الهدف (طلب المالك 2026-10-05): **القسم المعماري كاملًا بشكله الخارجي والداخلي قبل الانتقال لأي قسم آخر**. لا ينتقل العمل إلى بند إلا بعد إغلاق ما قبله بالقياس (`pipeline/audit_arch.py`) وبالصور.

الملاحظات التي طلبها المالك: أسقف عائمة، درج يخترق الخرسانة، جدران ناقصة، أدوار تبدو منفصلة من الخارج، خزانات غير موجودة، المكيفات وغيرها مكعبات ملونة قبيحة، نوافذ تبدأ من أرضية الغرفة (الصحيح: عتبة 60 سم)، إنارة مشغّلة، ستائر متنوعة، تفاصيل خارجية واقعية (ورق أشجار، بقع ماء في الأحواض الرملية)، «عدّل حسب الاعتمادات».
