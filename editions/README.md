# C4 — ست تجارب تسويقية تفاعلية

[افتح صفحة النسخ الست](https://binjednan.github.io/RD9-C4/editions/). تعمل الروابط مباشرة في المتصفح دون حساب، وتدعم العربية والإنجليزية.

| النسخة | رابط التشغيل | عائلة الرسم |
|---|---|---|
| Stone | [افتح التجربة](https://binjednan.github.io/RD9-C4/editions/c4-stone.html) | خريطة أبوظبي بطبقات ورقية مقطوعة، ولوحة عرض مركبة |
| Charcoal | [افتح التجربة](https://binjednan.github.io/RD9-C4/editions/c4-charcoal.html) | عدسات دائرية للنطاقات، وشبكة الشقق بحسب النمط |
| Azure | [افتح التجربة](https://binjednan.github.io/RD9-C4/editions/c4-azure.html) | تكبير من المنطقة إلى الموقع، ودوائر المسافات، وتدفق المساحة |
| Gallery | [افتح التجربة](https://binjednan.github.io/RD9-C4/editions/c4-gallery.html) | كتل الفئات المتناسبة، ومساحات الغرف، وكتالوج الأنماط |
| Studio | [افتح التجربة](https://binjednan.github.io/RD9-C4/editions/c4-studio.html) | المؤشرات، ومسار الشمس، والقطاع الرأسي |
| Promenade | [افتح التجربة](https://binjednan.github.io/RD9-C4/editions/c4-promenade.html) | شريط الوصول، والبرنامج الوظيفي، والتحليل الطبقي للموقع |

كل تجربة ملف HTML مستقل. تعرض كل نسخة لوحات المشروع المعتمدة من مجلد `drawings` المجاور؛ احتفظ به بجوار الملفات عند التنزيل. خريطة المنطقة: MapChart. الطرق: © مساهمو OpenStreetMap (ODbL).

المجسمات والرسوم معالجة بصرية من بيانات المشروع وليست صورًا للوضع المنفذ. الأثاث الحر والخامات والإضاءة توضيحية. الإيجارات سنوية بحسب إفادة المالك، وتوافر الوحدات غير مثبت.
